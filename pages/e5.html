Support et mise à disposition de services informatiques — Situations professionnelles réalisées en entreprise chez L4-Logistics.

Situations professionnelles
SP1

Sauvegarde automatisée des configurations des équipements réseaux

Mise en place de la solution rConfig V6 Core pour remplacer CatTools, permettant la sauvegarde automatisée des configurations de switchs, routeurs et firewalls via SSH sur le parc réseau de L4-Logistics.

rConfig SSH Réseau Automatisation
SP2

Mise en place d'un poste de production

Déploiement complet d'un poste Dell All-in-One en environnement de production : câblage, réservation DHCP par adresse MAC, masterisation via MDT, jonction au domaine Active Directory et placement dans l'UO Production.

Windows Server Active Directory DHCP MDT
SP3

Déploiement d'une architecture client-serveur : Active Directory, DHCP, GPO et pfSense

Déploiement d'une infrastructure virtualisée sous VMware avec un contrôleur de domaine Windows Server (AD DS, DNS, DHCP), un pare-feu pfSense centralisant les flux entre les réseaux Production, Administration et Serveur, et des GPO ciblées par profil utilisateur.

pfSense Active Directory GPO VMware DHCP Relay
SP4

Centralisation des logs et sécurité — SIEM Wazuh

Déploiement d'une solution SIEM (Wazuh) sur Ubuntu Server pour centraliser les journaux d'événements du pare-feu pfSense (Syslog) et du contrôleur de domaine Windows Server (agent Wazuh), avec détection des comportements suspects en temps réel.

Wazuh SIEM Syslog Linux Cybersécurité
